# VideoSaver Pro - SEO and Monetization Execution Plan

## Goal
- Increase qualified organic traffic.
- Rank core keywords around "video downloader" and long-tail platform queries.
- Prepare site for ad and affiliate monetization.

## Phase 1 (Week 1-2): Technical SEO Baseline
- Keep every indexable page with:
  - Unique title
  - Meta description
  - Canonical
  - Robots meta (`index, follow`)
  - One clear H1
- Keep XML sitemap and robots.txt updated after every content batch.
- Monitor Core Web Vitals in Search Console and optimize pages below "Good".

## Phase 2 (Week 2-6): Topical Authority Content
- Publish 2-3 high-intent guides weekly:
  - `download-[platform]-videos`
  - `how-to-save-[platform]-reels`
  - `best-[platform]-downloader`
- Update old guides monthly with:
  - Current year in headings where relevant
  - New FAQs
  - New internal links
- Build content clusters:
  - TikTok hub
  - Instagram hub
  - YouTube hub
  - Facebook hub

## Phase 3 (Week 3-8): Internal Linking and CTR
- Link homepage to key guides and influencer pages.
- Add "related guides" blocks on every article.
- Improve SERP CTR with:
  - Benefit-first titles
  - Strong meta descriptions
  - FAQ schema on intent-heavy pages

## Phase 4 (Week 4-10): Monetization
- AdSense:
  - Replace placeholder publisher id in `ads.txt`.
  - Add approved ad units above fold and inside long guides.
- Affiliate:
  - Add comparison tables in "best tools" articles.
  - Use marked sponsored links (`rel="sponsored nofollow"`).
- Conversion:
  - Add sticky CTA to download tool on guide pages.
  - Add email capture for updates and repeat traffic.

## Phase 5 (Ongoing): Authority and Links
- Acquire relevant backlinks from:
  - Tech tutorials
  - Social media creator blogs
  - Tool directories
- Publish original data posts (platform trends, download stats) for natural links.

## KPI Dashboard
- Organic clicks (Search Console)
- Indexed pages
- Average position for target keywords
- Revenue per 1,000 sessions (ads + affiliate)
- Conversion rate from article -> downloader use
